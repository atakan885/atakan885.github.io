Software Training & Digital Courses

My work

Created a Turkish-language Udemy course with 13 original Algodoo applications.

Workplace use

Design software onboarding with demonstrations, guided tasks and independent practice.

How I built the course

I created a Turkish-language Udemy course that starts with installation and core tools, then guides learners through 13 original Algodoo examples. Learners see how an application is built and can adapt the workflow to their own projects.

Workplace applications

For a software rollout, I would organise training around frequent user tasks. Each module can pair a short screen recording with a guided exercise and a reference sheet. A typical task might be setting up a report and checking the output before sharing it.

How to evaluate it

Ask a new user to complete the same type of task without step-by-step instructions. Track errors, support needed and time to the first successful result.
