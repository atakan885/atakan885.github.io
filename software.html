IMPLEMENTED WORK

What I developed

Algodoo Software Training — Published Udemy Course

I created a Turkish-language course that teaches Algodoo from installation and interface tools to original applications. The course includes 13 original application examples and practical guidance for teaching with the software.

▶Learn a tool. Complete a task.
WATCHPRACTISEAPPLY

The learning experience

The learning pathway combines explanation, demonstration and applied tasks. Learners follow the development of an application and can use the same approach for their own projects.

Evidence & evaluation

The published course is direct evidence of software training development. Course ratings and learner counts change, so they are not used as fixed performance claims here.

How I can apply this experience

I can create structured training for a software tool: onboarding modules, screen-based demonstrations, practice tasks and reference materials. I can work with product experts to align the course with real user tasks.

PROPOSED WORKPLACE APPLICATION

PROPOSED WORKPLACE LEARNING EXPERIENCE

01

Watch a demonstration

A short screen-based demonstration shows one useful workflow and explains the purpose of each step.

02

Complete a guided task

Learners complete the workflow with instructions and practice materials. Checks help them identify errors.

03

Work independently

Learners repeat the task without step-by-step guidance. The result shows whether they can use the tool independently.

Example scenario

A new user learns one workflow through a short demonstration, completes a guided task and then repeats it independently. Task-based checks show where more support is needed.

Potential deliverables: Course architecture · Video scripts · Software demonstrations · Practice tasks · Reference guides

Potential KPIs

Independent workflow completion · User errors · Time to first successful task
