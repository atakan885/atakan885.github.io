Machine Learning for Performance Insights

My work

Used eye-gaze data with my team to identify how attention differed by task type and inform later learning design.

Workplace use

Find recurring error patterns and test improvements against a performance baseline.

My role
Data analysis with the research team
Tools and methods
Eye tracking · task comparison

What the data showed

Our team compared where learners looked during different tasks in an AR lab. Procedural questions directed more attention to the physical components, while conceptual questions directed more attention to the visual representations. The pattern helped us decide which information to place where in subsequent learning activities.

Workplace applications

Combine task logs, time stamps and error records to find where learners repeatedly get stuck. For example, if rework clusters around one software step, inspect the instructions and workflow before deciding whether to change the training, interface or process.

How to evaluate it

Measure completion time, error rate or rework before and after a targeted change. Use patterns to decide what to investigate and follow up to check whether the intervention helped.
