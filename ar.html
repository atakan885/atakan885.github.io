AR/VR Learning Experiences

My work

Built a HoloLens app that links an interactive 3D detector to a physical LEGO model.

Workplace use

Equipment familiarisation, guided inspections and repeatable task practice.

My role
AR application development
Tools and methods
Unity · HoloLens · LEGO

How I built the experience

I built a Unity application for HoloLens that pairs a physical LEGO model with an interactive 3D view of the ALICE detector. Learners can select parts and explore how they fit together. Linking the digital view to a physical object makes the structure easier to inspect than a flat diagram.

Workplace applications

For equipment onboarding, a technician could identify a component on a real machine and see what to inspect. If the machine is unavailable, a VR version could recreate the task so learners can practise the sequence before working on the equipment.

How to evaluate it

Have learners repeat the inspection without on-screen prompts. Record missed checks, sequence errors and whether they can explain what each check is for.
