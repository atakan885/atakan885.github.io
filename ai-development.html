AI-Assisted App & Learning Content Development

My work

Used AI tools to develop this portfolio and prototypes for role-play, process simulation and adaptive practice.

Workplace use

Prototype branching scenarios and practice tools for review and learner testing.

How I build prototypes

I use tools such as OpenAI and Claude to turn learning objectives into working web prototypes. I define the task and feedback first, then refine the interface and interactions through testing. The five demos below run with predefined rules so you can try them directly.

Workplace applications

A subject expert could review a branching conversation before it is developed into training. A process owner could test a simulation with staff to see which decisions need practice. A software trainer could use a workflow exercise to check whether learners understand the order of key steps.

How to evaluate it

In a short pilot, observe where learners hesitate, what they choose and whether the feedback helps them improve. Use these observations to decide what to refine before a wider rollout.
